## Présentation du projet
Ce projet est réalisé dans le cadre de nos études en licence d'informatique. Il consiste à modéliser des missions spatiales et les différents éléments qui les entourent : équipages, zones à explorer et engins d'exploration.

Développé en Java, il met l'accent sur la programmation orientée objet, notamment à travers l'utilisation de l'héritage.
